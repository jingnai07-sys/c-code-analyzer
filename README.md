#**[C] CODE ANALYZER**

C言語初心者向けのコード支援ツール

行ごとの説明・疑似フローチャート・ミスヒントを表示します

##使い方

1.URLを開く

2.コードを入力

3.[解析する]を押す

4.解説、ミス・ヒントの項目の確認

##URL

https://jingnai07-sys.github.io/c-code-analyzer/

##主な機能

-行ごとの日本語解析

-フローチャート表示

-コード内のミス、ミスに関するヒント

-行番号・色分け・入力候補(CodeMirror)

##対応

if,for,while,switch,配列などの基本構文に取り扱っています。

複雑な構文に関しては、推定を含む場合があります。
