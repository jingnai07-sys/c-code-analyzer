c code analyzer

  • C CODE ANALYZER
  • 使い方
  • ご意見・不具合報告

1 自分が書いたコードを入力

C言語で書いたコードをコード入力欄に入力しよう

POINT

①　{}を選択し、数が足りているかを確認できる

ハイライトが赤い場合・・・{}が不足している
ハイライトが青い場合・・・{}の数は対応している

②　キーワード検索が可能

「Ctrl」＋「F」キーでキーワード検索ができます

2 「解析する」ボタンを押す

「解析する」ボタンを押して解析をしよう

解析するボタンを押すんだべ

3 結果を確認

画面を下にスクロールして、3つの項目を確認しよう

①　コードと説明

一行ずつコードの説明が書かれます

②　疑似フローチャート

コードに合わせフローチャートが自動で作成されます

③　ミス・ヒント

コードにミスがある場合、修正するためのヒントが表示されます

まずはサンプルからコードを選んで、試そう！

「SAMPLE：基本」「SAMPLE：if文」などのボタンを押すと、用意されたC言語のコードが自動入力されます。
まずは「SAMPLE：ミスあり」などを押して「解析する」を試してみると、ツールの動きがわかります

まずは動かすことが大事だべ
